PNG — Portable Network Graphics

A lossless raster format built for fidelity and transparency.

Type: Raster Extension: .png MIME: image/png Compression: Lossless Transparency: Yes

Best for: Graphics, screenshots and images requiring transparency.

What is PNG?

PNG stands for Portable Network Graphics.

PNG is a raster image format particularly useful when image fidelity or transparency needs to be preserved. Unlike ordinary JPEG compression, PNG doesn't need to discard image information to achieve its normal compression.

PNG is commonly used for

✓ Screenshots
✓ Graphics
✓ UI elements
✓ Images with transparent backgrounds
✓ Illustrations
✓ Logos when SVG isn't appropriate
✓ Images requiring lossless storage
Usually not ideal for:
✗ Large photographs on websites
✗ Hero photographs
✗ Large photo galleries
✗ Situations where minimum file size is critical

Modern WebP or AVIF can often produce considerably smaller files for web delivery than PNG for the same content.

Why are PNG files sometimes huge?

Because PNG prioritizes preserving image information rather than aggressively discarding it. A 4000×3000 photographic PNG can be many times larger than a visually similar compressed AVIF or WebP.

PNG vs WebP

WebP supports both transparency and lossless encoding, while often providing more efficient compression than PNG at a similar quality level.
