SVG — Scalable Vector Graphics

What SVG is, when to use it, and how it compares to raster formats like PNG.

Type: Vector Extension: .svg MIME type: image/svg+xml Transparency: Yes Animation: Yes Scalable: Yes

Best for: Logos, icons, illustrations, diagrams and interface graphics.

What is SVG?

SVG stands for Scalable Vector Graphics.

Unlike JPEG, PNG, WebP and AVIF images, which are primarily composed of pixels, SVG describes graphics using shapes, paths, coordinates and other instructions.

Because of this, an SVG can usually be enlarged or reduced without becoming pixelated. The SVG specification also allows graphics to contain shapes, images and text, and supports styling, transformations, clipping, masks, filters, interactivity and animation.

What is SVG used for?

SVG is particularly well suited for:

Logos

A company logo may need to appear at 24 pixels in a navigation bar and several thousand pixels on a large display. SVG can remain sharp at both sizes.

Icons

Interface icons, navigation elements and symbols are excellent candidates for SVG.

Illustrations

Simple illustrations composed of geometric shapes can often be stored efficiently as vectors.

Charts and diagrams

Graphs, maps and diagrams benefit from the resolution-independent nature of SVG.

Web interfaces

SVG elements can be styled and manipulated directly in web applications.

When should you use SVG?

Use SVG when:
✓ Creating a logo
✓ Creating an icon
✓ Working with geometric graphics
✓ The image must stay sharp at every size
✓ You need interactive or programmable graphics
Avoid SVG when:
✗ Working with photographs
✗ Working with complex photorealistic imagery
✗ Vectorizing would create thousands of unnecessary paths

For complex photographic content, raster formats such as AVIF, WebP or JPEG are generally more appropriate.

Can SVG have a transparent background?

Yes. SVG doesn't require a rectangular opaque background — objects can be drawn independently while the rest of the canvas stays transparent.

Can SVG lose quality?

A true vector SVG can be resized without the pixelation associated with enlarging raster images. However, an SVG can also contain embedded raster images — those embedded images remain resolution-dependent.
