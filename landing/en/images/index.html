NOXEL SPECTRA for images

NOXEL SPECTRA for images brings about twenty tools together on a single page. Pick an image, chain the operations and download the result.

Open Spectra for images

Formats and file size

  • Analyze: the image's format, dimensions and file size.
  • Convert: JPEG, PNG, WebP, AVIF or GIF, with a chosen quality or a target size in KB for JPEG, WebP and AVIF.
  • Batch processing: the same sequence of operations on up to 20 images (100 MB in total).
  • Clean metadata and Author and rights: remove a file's hidden information, or write your name and rights into it.

Dimensions and framing

  • Resize, Crop, Rotate / Flip.
  • Responsive sizes: several widths of the same image for a website.
  • Social media: crop to each network's format for profile photos, banners and posts, never stretched.

Editing and effects

  • Remove the background of a photo.
  • Filters / Adjustments, Drop shadow, Glow effect, Watermark.
  • Editor and Gradient to compose an image.

Logos and identity

  • Vectorize: turn a logo into an SVG.
  • Favicons: a site's full set of icons from a single logo.
  • Color palette: an image's dominant colors.

Limits to know

An image can be up to 25 MB. It is sent to our server for the time it takes to process, and it is not kept afterwards.
